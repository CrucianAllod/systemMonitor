# Система мониторинга ресурсов

## Описание

Этот проект представляет собой приложение для мониторинга системных ресурсов, написанное на Python с использованием библиотеки Tkinter для графического интерфейса и библиотеки psutil для получения информации о загрузке системы. Приложение записывает данные о загрузке процессора, использовании оперативной памяти и дискового пространства в базу данных SQLite.

## Функциональность

- Отображение текущей загрузки процессора, использования оперативной памяти и дискового пространства.
- Возможность записи данных о загрузке системы в базу данных.
- Просмотр истории записанных данных в виде таблицы.

## Установка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/username/my_project.git
   cd my_project
   ```
   
2. Создайте и активируйте виртуальное окружение:

    ```bash
    python -m venv venv
    source venv/bin/activate
    ```

3. Установите зависимости:

    ```bash
    pip install -r requirements.txt 
    ```

## Использование

1. Запустите приложение:
    ```bash
    python main.py 
    ```
2. В главном окне приложения вы увидите текущую загрузку процессора, использование оперативной памяти и дискового пространства.
3. Нажмите кнопку "Начать запись", чтобы начать запись данных о загрузке системы. Время записи будет отображаться на экране.
4. Нажмите кнопку "История", чтобы открыть новое окно с таблицей, отображающей историю записанных данных.
5. Чтобы остановить запись, нажмите кнопку "Остановить запись".

## Автотесты

В проекте настроены автоматические тесты, которые запускаются при каждом пуше в репозиторий или при создании pull request. 
Это позволяет гарантировать, что изменения не нарушают существующий функционал. 
Тесты выполняются с помощью GitHub Actions, и результаты можно просмотреть в разделе "Actions" репозитория.
